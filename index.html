How to get an SRT from a voiceover

Make your voiceover (your own voice, or a TTS tool like Google AI Studio), then ask a transcription tool to "transcribe this audio as an SRT file with sentence-level timestamps." Paste the result above. Keep the audio file — you'll load it when recording.
